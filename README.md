One funny single-line sport the Olympics rejected, written for the
[Rejected Olympic Sports](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da)
bounty on make.fun.

## Entry

> Synchronized Napping: four athletes nap in perfect unison; snoring costs a point, sleep-talking is a foul, and the gold goes to the team that dreams in formation.

## Run

```sh
python3 main.py
```

This writes the single entry line to `entry.txt` (and to `/output/entry.txt`
when that directory exists): one line, under 200 characters, byte-identical
on every run.
